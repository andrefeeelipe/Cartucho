O que vem no Cartucho

Só o que importa para jogar: escolher o jogo, ajustar controle, som e imagem.

  • Loja de jogos grátis

    Mais de 9 mil jogos liberados pelos próprios autores, para baixar dentro do app.

  • Biblioteca que se arruma sozinha

    Nome e capa de cada jogo aparecem sozinhos. Versões do mesmo jogo viram um item só.

  • Saves no seu Google Drive

    Comece no celular e continue no computador. Cada pessoa usa a própria conta.

  • Jogar com amigos

    Salas de 2 a 4 jogadores, perto ou longe, funcionando até nos dados móveis.

Também tem troféus do RetroAchievements, qualquer joystick, e no computador funciona com teclado.

Como instalar

No celular Android

  1. Toque em Android lá em cima, neste celular.
  2. Abra o arquivo baixado. Se o celular pedir, permita instalar apps desta fonte.
  3. Toque em Instalar e depois em Abrir.

No computador com Windows

  1. Clique em Windows lá em cima para baixar o instalador.
  2. Abra o arquivo. Se aparecer “O Windows protegeu o computador”, clique em Mais informações e em Executar assim mesmo.
  3. Abra o Cartucho pelo menu Iniciar.

Dúvidas

O Cartucho vem com jogos?

Não vem com jogos comerciais. A Loja dentro do app só tem jogos gratuitos, liberados pelos próprios autores. Para outros jogos, use apenas arquivos que são seus.

Quanto custa?

Nada. Não tem assinatura, compra dentro do app nem propaganda.

Qual arquivo de Android eu baixo?

Quase todo celular atual usa o arm64-v8a, que é o do botão principal. Se não tiver certeza, baixe o universal: é maior, mas funciona em qualquer aparelho.

Os jogos de PlayStation 2 fecham sozinhos. O que faço?

Coloque a BIOS do seu próprio console em Ajustes, BIOS, PlayStation 2. Com ela o Cartucho usa um motor mais rápido e estável. O app não traz a BIOS e não indica onde baixar.

Precisa de internet?

Só para a Loja, as capas, o backup no Drive, os troféus e as partidas online. Para jogar, não.

Como sei que o arquivo é seguro?

O código é aberto no GitHub e cada versão é montada lá, automaticamente. Se quiser conferir, compare o código SHA-256 do arquivo baixado com a lista publicada junto da versão.

Cartucho é um projeto independente e gratuito, sem ligação com fabricantes de videogames. Nomes de consoles citados pertencem aos seus donos.
